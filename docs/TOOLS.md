# Tools

| Area | Tools |
|---|---|
| Session | `whoami`, `start_login`, `login`, `capture_session`, `session_status` |
| Shopping | `search_products`, `get_product`, `shortlist_products`, `render_product_picker` |
| Memory | `get_shopping_memory`, `remember_product`, `forget_shopping_memory` |
| Cart | `get_cart`, `add_to_cart`, `add_shortlist_to_cart`, `set_cart_quantity`, `select_cart_items`, `remove_from_cart` |
| Checkout | `list_addresses`, `list_delivery_slots`, `select_delivery_slot`, `review_checkout`, `place_order` |
| History / diagnostics | `list_orders`, `probe_page` |

For lists and comparisons, start with `shortlist_products`, then `render_product_picker`. Plain structured results work when MCP Apps are unavailable.
